# Набор алгоритмов для поиска минимумов в разных функциях.

## 📚 Поддерживаемые функции

 **Розенброк**   -> `(1 - x)² + 100·(y - x²)²`
 
 **Химмельблау** -> `(x² + y - 11)² + (x + y² - 7)²`
 
 **Растригин**   -> `20 + x² + y² - 10·(cos(2πx) + cos(2πy))`

## ⚙️  Реализованные алгоритмы

 **Градиентный спуск** (`grad_descent.c`)
 
 **Имитация отжига** (`simulated_annealing.c`)
 
 **Генетический алгоритм** (`genetic_algorithm.c`) 

## 🚀 Использование

### Компиляция

```bash
make
```

### Запуск

```bash
./algo
```

### Интерактивное меню

Программа последовательно запрашивает:

1. **Выбор функции** (1-3)
   - `1` — Розенброк
   - `2` — Химмельблау
   - `3` — Растригин

2. **Количество стартовых точек** — число случайных начальных приближений

3. **Диапазон поиска** — `N` означает интервал `[-N, N]`

## 📊 Особенности функций

### Розенброк
- **Глобальный минимум:** `(1, 1)`, `f = 0`
- **Особенность:** узкий изогнутый овраг

### Химмельблау
- **Глобальные минимумы (4 точки):**
  - `(3.0, 2.0)`
  - `(-2.805118, 3.131312)`
  - `(-3.779310, -3.283186)`
  - `(3.584428, -1.848126)`
- **Значение:** `f = 0` во всех

### Растригин
- **Глобальный минимум:** `(0, 0)`, `f = 0`
- **Локальные минимумы:** во всех целых координатах `(k, m)` со значением `k² + m²`
